This code reconstructs convergence maps from simulated galaxy shear catalogs covering an octant of the sky. 
First, the shear components (\(\gamma_1\) and \(\gamma_2\)) are averaged into HEALPix maps. 
The spherical Kaiser–Squires method is then applied to reconstruct the E- and B-mode convergence fields (\(\kappa_E\) and \(\kappa_B\))
using spin-2 spherical harmonic decomposition. The resulting maps can be used to study the convergence field and assess potential B-mode 
contamination.
